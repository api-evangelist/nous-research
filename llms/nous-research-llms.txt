# Nous Research

> Nous Research ("The AI Accelerator Company") builds open-weight Hermes language models and runs Nous Portal, an OpenAI-compatible inference API at inference-api.nousresearch.com that aggregates Hermes plus 280+ third-party models with OpenRouter-style routing. The API uniquely supports the x402 payment protocol, returning HTTP 402 with a Solana USDC micropayment envelope for agentic pay-per-request access. Backed by Paradigm.

This llms.txt was GENERATED by the API Evangelist enrichment pipeline from the catalog and live API probes (no provider-published llms.txt was found at /llms.txt).

## API
- [Nous Research Inference API (Nous Portal)](https://portal.nousresearch.com/docs): OpenAI-compatible chat completions + model catalog. Base URL https://inference-api.nousresearch.com/v1
- [OpenAPI (derived)](openapi/nous-research-inference-api-openapi.yml): GET /v1/models (public), POST /v1/chat/completions (Bearer API key or x402)

## Endpoints
- GET /v1/models: list available models with pricing, context length, and supported parameters (public, no auth)
- POST /v1/chat/completions: OpenAI-compatible chat completions; supports SSE streaming and x402 payment
